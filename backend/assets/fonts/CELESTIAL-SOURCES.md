# Celestial horoscope fonts

Approved by the user on 2026-09-08. The server loads bundled font files only; no Windows fonts or per-post network font downloads are required.

Source revision: `google/fonts@5e35378e6bda803962ee6fd257e444a7d459660d`.

- NotoSansJP-VF.ttf: [Noto Sans JP](https://github.com/google/fonts/tree/5e35378e6bda803962ee6fd257e444a7d459660d/ofl/notosansjp), original NotoSansJP[wght].ttf; unchanged font data. License: NotoSansJP-OFL.txt. Guidance at weight 400.
- BIZUDGothic-Regular.ttf: [BIZ UD Gothic](https://github.com/google/fonts/tree/5e35378e6bda803962ee6fd257e444a7d459660d/ofl/bizudgothic). License: BIZUDGothic-OFL.txt. Metadata text.
- NotoSansSymbols-VF.ttf: [Noto Sans Symbols](https://github.com/google/fonts/tree/5e35378e6bda803962ee6fd257e444a7d459660d/ofl/notosanssymbols), original NotoSansSymbols[wght].ttf; unchanged font data. License: NotoSansSymbols-OFL.txt. Zodiac symbols at weight 400 replace the preview's Windows-only Segoe UI Symbol; signs remain at the same size and position independently of symbol width.
- Existing NotoSerifJP-VF.ttf is retained for title/sign names at weight 600. [Noto Serif JP license](https://github.com/google/fonts/blob/5e35378e6bda803962ee6fd257e444a7d459660d/ofl/notoserifjp/OFL.txt) is included as NotoSerifJP-OFL.txt.

Font binaries are unmodified; `-VF` filenames simply replace the distribution's `[wght]` filenames. Copyright notices and SIL OFL texts are distributed alongside the fonts.
