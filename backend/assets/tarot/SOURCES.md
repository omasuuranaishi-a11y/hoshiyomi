# Tarot image sources

The `major-XX-rws1909-v1.jpeg` files are scans of the original 1909
Rider–Waite–Smith “Roses & Lilies” deck illustrated by Pamela Colman Smith.

- Primary source collection: https://commons.wikimedia.org/wiki/Category:Rider-Waite_tarot_deck_(Roses_%26_Lilies)
- Public mirror used to complete the fixed local set: https://github.com/mixvlad/TarotCards/tree/main/tarot/rider-waite/720px
- The mirror metadata records Wikimedia Commons as its source and the deck as Public Domain.
- Source category: https://commons.wikimedia.org/wiki/Category:Rider-Waite_tarot_deck
- Rights status shown by Wikimedia Commons: Public domain
- Retrieval script: `scripts/sync_rws1909_major_arcana.ps1`

Only the original RWS1909 scans are used. Later recolored or AI-generated
derivatives are not part of the automatic story pipeline.
